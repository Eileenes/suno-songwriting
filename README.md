# Suno Songwriting · 歌词与配置创作技能

把一句灵感、一个故事或一组音乐要求，整理成可直接复制到 Suno 的完整歌词、Styles、Exclude 和配置建议。

这是一个以中文创作为重点的 Codex Skill，支持其他歌词语言。它输出创作文本与设置建议，不自带音频生成、Suno 登录或付费 API。

## 能做什么

- 创作完整歌曲，或只修改已有歌词、风格与参数。
- 围绕具体场景组织叙事，检查副歌韵脚、自然语义与换气空间。
- 按目标时长、BPM 和小节数规划结构，为前奏、solo 和渐弱尾奏预留空间。
- 给复杂配器分配主旋律、对答、和声、节奏与低音职责。
- 区分真实界面控件与写入 Styles 的音乐目标，必要时查 Suno 官方资料。

## 安装

把本仓库作为一个技能目录放入个人技能路径。首次安装、目标目录尚不存在时：

```bash
git clone https://github.com/Eileenes/suno-songwriting.git "${CODEX_HOME:-$HOME/.codex}/skills/suno-songwriting"
```

如果已经安装同名技能，请先比较和保留自己的修改，不要直接覆盖。支持 `SKILL.md` 的其他代理可按各自技能目录规则安装。

## 使用

在支持技能的会话中调用：

```text
$suno-songwriting
写一首中文流行歌曲，约 2 分 30 秒，女声有穿透力、节奏比较快。
歌词要押韵，开头有渐进过渡，结尾渐弱，中间有弦乐 solo，
弦乐丰富且有不同声部的呼应。主题你来决定。
```

也可以只提供一个想法：

```text
$suno-songwriting
写一首下班独自回家的歌，疲惫但温暖，偏独立流行。
```

修改时保留上下文：

```text
$suno-songwriting
保留现有主歌和音乐风格，只改副歌。副歌主要押 ang 韵，
不要为了押韵改变意思，核心句保留“绿灯亮了”。
```

纯音乐也可以：

```text
$suno-songwriting
做一个约 60 秒的纯器乐片段，以大提琴为主，不要演唱和哼唱，
前半段克制，后半段展开，给我 Styles 与设置建议。
```

## 交付内容

完整创作通常输出歌名、歌词、Styles、Exclude、配置表，以及按需提供的编曲预算和最多三条试听调整。每个需要粘贴的文本字段独立放在代码块内；局部修改只返回受影响部分。

将这些字段分别粘贴到 Suno，而不是把整份技能说明放入歌词框。

## 设计重点与限制

- 时长先规划再写词。例如 128 BPM、4/4 下，80 小节约为 150 秒；这是编曲预算，不是生成时长保证。
- 结构标签、独奏安排、渐弱和人声描述都是引导。精确长度或局部音频效果可能仍需要生成后的编辑。
- 不将女声、快节奏或弦乐写成通用默认；保留用户的创作选择。
- 不把滑块数值说成官方最佳设置，也不假设用户拥有某个模型、付费功能或参考素材。
- Suno 控件会随版本变化，技能附有官方查证入口；无联网能力时仍能创作，但会标注未核实选项。
- 这里提供的是工作流说明，未宣称已经在 Suno 生成并试听验证。
